# Вместе — онлайн-кинотеатр

Простой сайт: загружаешь видео, скидываешь ссылку на комнату другу — смотрите синхронно, с чатом.

## Что внутри
- `server.js` — сервер (Node.js + Express + Socket.io + Multer)
- `public/index.html` — весь фронтенд (вход в комнату, плеер, чат)
- `uploads/` — сюда будут падать загруженные видео

## Возможности
- Синхронное воспроизведение видео (загруженный файл, прямая ссылка, **YouTube** или ссылка на стрим)
- Чат в реальном времени: текст, скриншоты/фото (вставка через Ctrl+V или кнопка-скрепка), GIF, голосовые сообщения, реакции на сообщения, ответы на сообщения
- Профиль: своё имя, эмодзи-аватар или загруженное фото — видны остальным в комнате
- Тёмная/светлая тема, уведомления о новых сообщениях
- Фоновая работа: видео продолжает играть при сворачивании (Media Session + Wake Lock + ручной Picture-in-Picture), push-уведомления о сообщениях приходят даже с полностью закрытым приложением
- @упоминания в чате, крестики-нолики как мини-игра, свайп вправо по сообщению — быстрый ответ

## Важно после обновления
Добавилась зависимость `web-push` — один раз выполни `npm install` перед запуском.
VAPID-ключи для push-уведомлений сервер генерирует сам при первом старте и
сохраняет в `vapid-keys.json` рядом с `server.js` — руками ничего вписывать не нужно.

## YouTube с синхроном
Ссылка на YouTube (youtube.com/watch, youtu.be, /shorts/, /live/) грузится через
официальный YouTube IFrame Player API — не голый iframe, а плеер, которым можно
управлять программно. Play/pause/перемотка синхронизируются между всеми зрителями
комнаты по-настоящему, через тот же канал, что и для загруженных файлов.
Ограничения — со стороны самого YouTube, не наши: если автор видео запретил
встраивание, оно не откроется вообще (по клику на «Открыть на YouTube» можно
посмотреть напрямую); возрастные видео на сторонних сайтах не встраиваются.

## AI-помощник в чате
Команда `/ai <вопрос>` в чате (или кнопка 🤖 рядом с чатом) отвечает через
Gemini API — например «/ai кто этот актёр», «/ai объясни, что вообще
происходит», «/ai что за трек сейчас играет». AI видит только текст чата
комнаты (последние ~24 реплики) и свои общие знания — саму видео/аудио-
дорожку он не смотрит и не слушает, поэтому лучше всего отвечает, когда
название фильма/сериала/трека уже прозвучало в переписке.

Нужен свой ключ в переменной окружения `GEMINI_API_KEY`:
1. Зайди на [aistudio.google.com](https://aistudio.google.com/apikey)
2. **Get API key → Create API key** (нужен только аккаунт Google, без карты)
3. Добавь ключ как `GEMINI_API_KEY` в переменных окружения проекта на Railway/Render
4. (Опционально) `GEMINI_MODEL` — если нужна конкретная модель, по умолчанию `gemini-2.5-flash`

Без ключа `/ai` ответит подсказкой о настройке — остальной сайт продолжает
работать как обычно. Ответ виден всем в комнате, ошибка/подсказка о ключе —
только тому, кто спросил.

## GIF в чате
Поиск GIF работает через Giphy API. Общий публичный demo-ключ Giphy сейчас
нестабилен (перегружен другими проектами и часто отдаёт ошибку 403), поэтому
нужен свой ключ — это бесплатно и занимает буквально минуту, модерация не
нужна:

1. Зарегистрируйся на [developers.giphy.com](https://developers.giphy.com/)
2. Нажми "Create an App" → выбери **API** (не SDK) → дай приложению любое название
3. Ключ (`API Key`) появится сразу же на странице приложения — скопируй его
4. Добавь его как переменную окружения `GIPHY_API_KEY` в настройках проекта на Railway/Render (Variables/Environment)
5. Перезапусти сервис — готово, поиск GIF заработает

Без ключа кнопка GIF покажет подсказку об этом — остальной сайт продолжает работать как обычно.

## Фото на аватар
В профиле рядом с выбором эмодзи есть кнопка «Загрузить фото» — она
отправляет картинку на сервер (эндпоинт `/upload-avatar`, до 8 МБ) и
показывает её как аватар вместо эмодзи/инициалов, синхронизируясь с
другими участниками комнаты. Кнопка «Убрать фото» возвращает эмодзи/инициалы.
Фото хранятся в `uploads/avatars/` и автоматически удаляются через
60 дней (настраивается переменной `AVATAR_MAX_AGE_DAYS`).

## Голосовые сообщения
Кнопка с иконкой микрофона в чате запускает запись через `MediaRecorder`
(нужен доступ к микрофону — браузер сам спросит разрешение). Готовая запись
загружается на сервер (`/upload-voice`, до 10 МБ, лимит записи — 5 минут) и
рассылается остальным как обычное сообщение с плеером (play/pause, полоска
прогресса, таймер). Хранится в `uploads/voice-messages/` и автоматически
чистится через `FILE_MAX_AGE_DAYS` дней (по умолчанию 3), как и картинки чата.
Работает в Chrome/Firefox/Edge; в старых версиях Safari запись может
использовать другой формат аудио.

## Как запустить с телефона (без компьютера)

Проще всего через **Railway** — там можно загрузить проект прямо из браузера телефона.

1. Зарегистрируйся на [railway.app](https://railway.app) (можно через GitHub или Google)
2. Создай пустой репозиторий на GitHub через мобильное приложение GitHub или сайт github.com:
   - New repository → назови, например, `roomly`
   - Загрузи туда все файлы этого проекта (в GitHub есть кнопка "Add file → Upload files", это работает в мобильном браузере)
3. В Railway: New Project → Deploy from GitHub repo → выбери свой репозиторий
4. Railway сам определит Node.js проект и запустит `npm install` + `npm start`
5. В настройках проекта включи **Public Networking**, чтобы получить публичную ссылку (что-то вроде `roomly-production.up.railway.app`)
6. Готово — открывай ссылку с телефона и зови друзей

**Альтернатива — Render.com**: тот же принцип (New Web Service → подключить GitHub репозиторий → Build command `npm install`, Start command `npm start`), тоже полностью настраивается из браузера.

## Важно про размер видео и хостинг
- Бесплатные тарифы Railway/Render дают ограниченное место на диске (обычно 1–5 ГБ) и он **не постоянный** — при переразвёртывании файлы могут удалиться
- Для фильмов лучше не хранить видео прямо на сервере, а подключить облачное хранилище (например, Backblaze B2 или Cloudflare R2 — у обоих есть бесплatный тариф). Если понадобится — могу переделать код под это
- Учитывай отдачу (bandwidth) — у бесплатных тарифов есть лимиты в месяц

## Как пользоваться
1. Открой ссылку на сайт
2. Введи имя и код комнаты (просто придуманное слово — его же скажи другу)
3. Загрузи видеофайл кнопкой "📁 Загрузить видео" (или выбери уже загруженное из списка)
4. Плеер, пауза и перемотка синхронизируются у всех, кто в комнате
5. Рядом — чат

## Новое в этой версии

Девять улучшений поверх существующего Roomly — ничего из старого не
удалялось, всё это работает поверх той же архитектуры (`server.js` +
единый `public/index.html`), новый серверный код вынесен в `server/`.

1. **Автоопределение видео/фильма** — при загрузке файла сервер сразу
   разбирает имя файла в чистое название (`The.Dark.Knight.2008...` →
   «The Dark Knight», 2008) и технические данные (длительность, разрешение
   через ffprobe). Если задан `TMDB_API_KEY`, фоном подтягивается постер,
   рейтинг и описание с TMDB — карточка над плеером дозаполняется сама,
   ничего не перезагружая. Без ключа — просто показывается название и
   технические данные, загрузка видео никогда не блокируется этим шагом.
2. **Умный реконнект** — при разрыве соединения клиент переподключается
   автоматически, заново входит в комнату и восстанавливает видео,
   позицию, play/pause, чат и присутствие. Дубликаты "присоединился"
   в чате подавляются по clientId + грейс-периоду.
3. **Статус синхронизации** — пилюля в шапке комнаты показывает
   Подключено / Синхронизация / В синхроне / расхождение в секундах /
   Соединение потеряно. Дрейф считается на клиенте без лишних запросов:
   сервер шлёт время + версию состояния при каждом play/pause/seek,
   клиент сверяет со своим плеером раз в 2 секунды.
4. **Улучшенный чат** — закреп важного сообщения (📌, кнопка у каждого
   сообщения), поиск по истории чата (иконка-лупа в шапке чата), вкладки
   "Все / @ Упоминания" для фильтрации.
5. **Присутствие** — кнопка со счётчиком зрителей теперь открывает список
   участников со статусами (Смотрит / Пауза / Пишет в чат /
   Переподключение).
6. **Таймлайн комнаты** — компактная история важных событий (создание
   комнаты, вход/выход, начало/пауза просмотра, реакции) — открывается
   иконкой-часами в шапке.
7. **Живая активность** — короткие всплывающие тосты поверх видео
   ("Anna присоединилась", "▶ начался просмотр") для самых заметных
   событий; дедуплицируются по id, не дублируются после реконнекта.
8. **Облачное хранилище (Cloudflare R2)** — `server/storage.js`
   абстрагирует, где физически лежит видео. По умолчанию всё работает
   локально (`uploads/`), как и раньше. Если задать `STORAGE_PROVIDER=r2`
   и все `R2_*` переменные и установить `@aws-sdk/client-s3`
   (`npm install @aws-sdk/client-s3`), файлы дополнительно заливаются в
   R2, а `/video/:filename` стримит их оттуда с поддержкой перемотки
   (Range-запросы). Без выполнения всех этих условий — тихий откат на
   локальное хранилище, ничего не ломается.
9. **Автопревью видео** — после загрузки сервер фоном вызывает FFmpeg,
   чтобы вытащить кадр примерно на 15% длительности (не чёрный кадр
   заставки) и сохранить как превью. Если FFmpeg не установлен —
   загрузка всё равно работает, просто без превью.

### Новые переменные окружения (все необязательные)

```
TMDB_API_KEY=              # ключ TMDB для постеров/рейтинга/описания
STORAGE_PROVIDER=local     # local (по умолчанию) или r2
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET_NAME=
R2_PUBLIC_BASE_URL=        # опционально, для прямых ссылок на файлы
FFMPEG_PATH=ffmpeg         # переопредели, если ffmpeg не в PATH
FFPROBE_PATH=ffprobe
```

Ни одна из этих переменных не обязательна — без них Roomly работает
ровно так же, как и раньше (локальное хранилище, без постеров, без
превью).

### Известные ограничения
- Метаданные и хранилище живут в памяти процесса — перезапуск сервера
  сбрасывает их (как и всё остальное состояние комнат в этом проекте).
- Разбор жанров с TMDB не реализован (генре-id → названия не маппятся) —
  показываются только название/год/рейтинг/описание/постер.
- Статус "Пишет в чат" у участника не возвращается автоматически обратно
  в "Смотрит/Пауза" по таймеру — обновится при следующем его play/pause.
- R2-загрузка требует `npm install @aws-sdk/client-s3` — без этого пакета
  режим `r2` автоматически откатывается на локальное хранилище с
  предупреждением в логах сервера.
